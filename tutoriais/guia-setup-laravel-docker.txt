# Guia — Rodar o projeto pela primeira vez em outro PC

## 1. Instalar o necessário

No PC novo, instale:

* **Docker Desktop**
* **Git**

Não precisa instalar **XAMPP, PHP, Composer, MySQL ou Node.js** no Windows, porque eles serão executados dentro dos containers Docker.

---

## 2. Baixar o projeto

Abra o PowerShell e faça:

```bash
git clone URL_DO_SEU_REPOSITORIO
```

Entre na pasta do projeto:

```bash
cd PROJETO-FINAL-2026
```

---

## 3. Criar o `.env`

Se o arquivo `.env` não estiver no GitHub, copie o `.env.example`:

```powershell
copy .env.example .env
```

Abra o `.env` e verifique se o banco está configurado assim:

```env
DB_CONNECTION=mysql
DB_HOST=db
DB_PORT=3306
DB_DATABASE=projeto
DB_USERNAME=root
DB_PASSWORD=root
```

> **Importante:** dentro do Docker, o `DB_HOST` deve ser `db`, e não `127.0.0.1` ou `localhost`.

---

## 4. Criar e iniciar os containers

Execute:

```bash
docker compose up -d --build
```

Confira se os containers estão funcionando:

```bash
docker compose ps
```

O `app` e o `db` devem aparecer como **Up**.

---

## 5. Instalar as dependências do Laravel

Execute:

```bash
docker compose exec app composer install
```

Isso instala as dependências do `composer.json` dentro do container, incluindo o **Laravel Pail**, caso ele esteja listado no projeto.

Depois gere a chave da aplicação:

```bash
docker compose exec app php artisan key:generate
```

Agora rode as migrations:

```bash
docker compose exec app php artisan migrate
```

> **Atenção:** se o projeto já possuir um banco/arquivo SQL que precisa ser importado, **não rode o `migrate` antes de importar esse banco**. Nesse caso, importe o banco primeiro.

---

## 6. Instalar as dependências do Node

Execute:

```bash
docker compose exec app npm install
```

Isso instala as dependências do `package.json` dentro do container.

---

## 7. Limpar os caches do Laravel

Depois que o Composer estiver instalado, execute:

```bash
docker compose exec app php artisan optimize:clear
```

Se aparecer:

```text
Class "Laravel\Pail\PailServiceProvider" not found
```

significa que as dependências do Composer não foram instaladas corretamente. Nesse caso, rode novamente:

```bash
docker compose exec app composer install
```

e depois:

```bash
docker compose exec app php artisan optimize:clear
```

---

## 8. Rodar o projeto

Se o `docker-compose.yml` já estiver configurado para iniciar o servidor Laravel automaticamente, basta acessar:

```text
http://localhost:8000
```

Para conferir os containers:

```bash
docker compose ps
```

---

# 🔄 Nas próximas vezes

Depois que o projeto já foi configurado uma vez, **não precisa repetir todo o processo**.

Entre na pasta:

```bash
cd PROJETO-FINAL-2026
```

Inicie os containers:

```bash
docker compose up -d
```

Acesse:

```text
http://localhost:8000
```

### Para desligar o projeto:

```bash
docker compose down
```

### Para ligar novamente:

```bash
docker compose up -d
```

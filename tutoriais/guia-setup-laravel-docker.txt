GUIA RÁPIDO — RODAR O PROJETO EM OUTRO PC

1. INSTALAR

Instale no computador:

- Docker Desktop
- Git

Não precisa instalar XAMPP, PHP, Composer, MySQL ou Node.js.

2. BAIXAR O PROJETO

Abra o PowerShell e execute:

git clone URL_DO_REPOSITORIO
cd portal-de-estagio

3. CONFIGURAR O .ENV

Se não existir o arquivo .env:

copy .env.example .env

Confira se o banco está configurado assim:

DB_CONNECTION=mysql
DB_HOST=db
DB_PORT=3306
DB_DATABASE=projeto
DB_USERNAME=root
DB_PASSWORD=root

4. INICIAR O PROJETO

Execute:

docker compose up -d --build

5. CONFIGURAR O LARAVEL

Execute um comando por vez:

docker compose exec app composer install

docker compose exec app php artisan key:generate

docker compose exec app php artisan migrate

docker compose exec app npm install

docker compose exec app php artisan optimize:clear

6. ACESSAR O PROJETO

Abra o navegador:

http://localhost:8000

---

PRÓXIMAS VEZES

Para iniciar:

docker compose up -d

Para desligar:

docker compose down

Pronto! Não precisa repetir a configuração inicial.



OBSERVAÇÃO:
Caso queira que outros dispositivos se conectem ao programa, entre em ip.da.maquina:8000
